# 私人数据与发布

公开仓库包含源码、许可证、通用配置、测试样例和经维护者明确授权的项目展示素材。运行后产生的内容属于本地使用者的数据。

以下内容不应进入公开仓库或发行压缩包：`.env`、`.runtime`、`.cache`、`.tools`、数据库及 WAL/SHM、Cookie、API Key、微信登录凭据和二维码、SSH 私钥、真实账号/群/成员 ID、群聊和朋友圈原文、人物画像、日记、人工标签、私人媒体素材及调试日志。

README 使用的角色头像是维护者单独允许公开的展示素材，来源和检查说明见 [展示素材清单](assets/README.md)。这个授权不包含其他群友的头像、聊天截图或运行时图库。

示例账号和群只演示格式；不是可用于登录或发送的真实目标。修改自己的昵称映射、网络配置或模型凭据后，不要反向复制到示例文件。

## 模型和网络

本地保存记忆不等于所有推理都在本地。选择云端模型时，相关聊天上下文、检索结果和媒体可能发送给所选提供方。使用自己的账号、群范围和模型配置；不要公开请求原文或包含凭据的错误日志。

默认安装不自动修改 hosts 或路由。若明确启用网络修复，启动器可能请求管理员权限，并记录本地恢复信息；这些记录不属于公开材料。

## 再发布检查

运行 `npm.cmd run release:check` 检查被跟踪文件中的常见凭据、意外数据目录、二进制和明显账号标识。规则扫描不能代替人工审查：测试内容、截图、压缩包和提交作者邮箱也需要检查。

发布源码包应从经过审查的 Git 提交生成，不要压缩整个运行目录。该仓库从新历史开始，未包含开发者旧仓库、恢复分支或内部审计补丁。真实问题反馈使用虚构案例和脱敏错误，避免附带数据库或完整日志。
