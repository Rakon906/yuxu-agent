# 功能范围

鱼叙通过同一个原生微信登录态收发群消息及处理朋友圈，不要求为了表情或朋友圈再登录一份桌面微信。

已实现的代码包括自主群聊、证据关联的长期记忆和人物观察、日记检索、跨天跟进、兴趣订阅、图片/表情理解缓存、语音、引用、拍一拍、图片发送及朋友圈互动。具体模块见 README。

发布时保留以下边界：

- Agent 的社交编排以授权群为范围；不把原生 CLI 的能力等同于已经完成私聊 Agent。
- 普通分享卡片、文章正文和合并转发各有独立解析流程。小程序、视频号和所有网页不是统一保证可读。
- 普通视频通过有限抽帧和音轨转写理解，不保证理解每一秒。旧式视频消息或无法下载的媒体会保留未理解状态。
- 模型理解可能出错；视觉描述不是群友原话，记忆保留来源和人物关联。
- 表情包使用微信表情发送通道；库中必须有经过核验的可用资源。空库不会凭空产生可发送表情。
- 朋友圈图像下载、消息收发和登录依赖微信服务及账号状态；离线测试不是所有真实环境的验收证明。
- 完整启动器当前针对 Windows x64。原生 Rust 组件包含其他平台实现，但整个 Agent 尚不承诺 Linux/macOS 一键安装。
- 当前 Windows 原生测试已通过；官方客户端数据接管仍是 Linux 专用功能，Windows 会拒绝该操作并保留资料，不影响原生通道自己的登录。详见 [验证记录](validation.md)。本次没有用新的微信账号完成端到端登录验收。
- 本地模型通过配置端点使用，不依赖某一型号工作站；模型权重和私有部署均不随源码分发。

人设是可替换的群聊风格。群内参与限制、来源核对和发送去重由代码实现，不能仅靠修改人设提示词绕过。
